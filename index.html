📐 Bentuk Umum Persamaan Kuadrat
Persamaan kuadrat adalah persamaan yang variabelnya berpangkat tertinggi 2. Bentuk umumnya:
ax² + bx + c = 0
Keterangan:
• x = variabel
• a = koefisien x², dengan syarat a ≠ 0
• b = koefisien x
• c = konstanta
• a, b, c ∈ ℝ
Persamaan
y = x² − 4
Diskriminan
16
Banyak Akar Real
2

📌 Kesimpulan

Grafik y = x² − 4 memotong sumbu X di 2 titik (dua akar real berbeda).

Catatan
Grafik persamaan kuadrat berbentuk parabola. Jika a > 0 terbuka ke atas, jika a < 0 terbuka ke bawah.
🎯 Tujuan: Setelah slide ini, kamu mampu menentukan akar-akar persamaan kuadrat dengan 3 cara: faktorisasi, kuadrat sempurna, dan rumus ABC.
🔍 Akar-akar Persamaan Kuadrat
Akar-akar persamaan kuadrat adalah nilai variabel x yang membuat persamaan bernilai benar. Akar-akar biasanya dinotasikan x₁ dan x₂.
① Faktorisasi
Ubah ax² + bx + c menjadi bentuk (x − x₁)(x − x₂) = 0. Gunakan dua bilangan yang jika dijumlah = b dan dikali = a·c.
② Kuadrat Sempurna
Ubah ke bentuk (x + p)² = q, lalu tarik akar kedua ruas:
x + p = ±√q.
③ Rumus ABC (Rumus Kuadratik)
x₁,₂ = ( −b ± √(b² − 4ac) ) / (2a)
Contoh 1 – Faktorisasi: Tentukan akar-akar dari x² + 2x − 35 = 0.

Cari dua bilangan yang jumlah = 2 dan kali = −35 → yaitu 7 dan −5.
Faktornya: (x + 7)(x − 5) = 0
Jadi: x = −7 atau x = 5.
Contoh 2 – Rumus ABC: Tentukan akar dari x² + 2x − 35 = 0.

a = 1, b = 2, c = −35
x₁,₂ = ( −2 ± √(2² − 4·1·(−35)) ) / (2·1) = ( −2 ± √(4 + 140) ) / 2 = ( −2 ± √144 ) / 2 = ( −2 ± 12 ) / 2
x₁ = (−2 + 12)/2 = 5  |  x₂ = (−2 − 12)/2 = −7
Jadi: x₁ = 5 dan x₂ = −7. ✔
Kesimpulan
Ketiga cara menghasilkan akar yang sama. Faktorisasi paling cepat jika bilangan mudah difaktorkan. Rumus ABC selalu bisa digunakan untuk semua bentuk persamaan kuadrat.

📊 Diskriminan & Jenis Akar
Diskriminan disimbolkan dengan D dan dirumuskan:
D = b² − 4ac
D > 0
2 akar real berbeda
Grafik memotong sumbu X di 2 titik
D = 0
2 akar real kembar
Grafik menyinggung sumbu X
D < 0
Tidak ada akar real
Grafik tidak menyentuh sumbu X
Contoh: Tentukan jenis akar dari 2x² − 8x + 8 = 0.
a = 2, b = −8, c = 8
D = b² − 4ac = (−8)² − 4(2)(8) = 64 − 64 = 0
Karena D = 0, maka persamaan memiliki dua akar real kembar.
🎯 Tujuan: Setelah slide ini, kamu mampu menghitung jumlah, hasil kali, dan selisih akar-akar tanpa harus mencari akarnya terlebih dahulu.
➕ Operasi Akar-akar Persamaan Kuadrat
Jika x₁ dan x₂ adalah akar-akar dari ax² + bx + c = 0, maka berlaku rumus berikut.
Jumlah Akar
x₁ + x₂ = −b/a
Hasil Kali Akar
x₁ · x₂ = c/a
Selisih Akar
|x₁ − x₂| = √D / a     (dengan D = b² − 4ac)
Contoh: Jika x₁ dan x₂ akar dari x² − 5x + 6 = 0, tentukan x₁ + x₂, x₁ · x₂, dan |x₁ − x₂|.
a = 1, b = −5, c = 6, D = 25 − 24 = 1
• x₁ + x₂ = −(−5)/1 = 5
• x₁ · x₂ = 6/1 = 6
• |x₁ − x₂| = √1 / 1 = 1
Diskriminan D
1
x₁ + x₂
5
x₁ · x₂
6
|x₁ − x₂|
1
